# Brand blocklist for LEGAL.BRAND. One mark per line, case-insensitive.
# Matching is on whole tokens: names are folded to plain ASCII (full-width
# forms, accents and Cyrillic/Greek lookalikes), then split on
# non-alphanumerics, camelCase, ALLCAPS runs ("BMWLogo") and letter/digit
# boundaries ("SM_Ford01"). Multi-word marks match as consecutive tokens or
# joined ("burger king" also matches "BurgerKing" and "burger_king").
#
# Deliberately NOT listed because they are ordinary words that show up in
# asset names: subway, puma, jaguar, mustang, beetle, dove, apple, shell,
# sonic, dominos, supreme, coach, guess, mini, seat, smart, genesis, polo,
# dodge, fiat, citadel. Those brands are listed by model or full name
# instead ("dodge viper", "fiat 500").
# Not listed: openlock / printable scenery. This repo's docs discuss the
# OpenLOCK license by name (docs/TODO.md, docs/print.md), so the repository
# brand scan would flag them; review OpenLOCK naming by hand.
# Exemptions (phrases such as "tesla coil") go in data/brand_allowlist.txt.
